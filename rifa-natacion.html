📜 Script SQL para Supabase

Copia este código y ejecútalo en el SQL Editor de tu proyecto Supabase para activar la base de datos:

Tabla de boletas CREATE TABLE IF NOT EXISTS public.boletas ( numero INT PRIMARY KEY, nombre TEXT NOT NULL, telefono TEXT NOT NULL, email TEXT, metodo_pago TEXT NOT NULL DEFAULT 'bre_b_nu', comprobante TEXT, estado TEXT NOT NULL DEFAULT 'pendiente', created_at TIMESTAMPTZ DEFAULT NOW() ); -- 2.
